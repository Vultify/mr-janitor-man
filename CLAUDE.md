# Mr Janitor Man website

Public website for Mr Janitor Man, the Discord bot for the Vultify server: a home page, Terms of Service and Privacy Policy. Plain HTML and CSS, with no build step.

- Live at https://vultify.github.io/mr-janitor-man/, served by GitHub Pages from `main` of the public repo `Vultify/mr-janitor-man`.
- The TikTok developer app and the bot's Discord bio link to `/`, `/terms.html` and `/privacy.html`, so keep those addresses working.
- The repo must stay **public**. Making it private turns GitHub Pages off and takes the site down.
- The bot's code is in `D:\Projects\Discord bot` (private repo `Vultify/mr-janitor-man-bot`). Read its `CLAUDE.md` for how the bot works.

## Making a change
1. Edit `index.html`, `terms.html`, `privacy.html` or `style.css` (shared navy, cyan and chrome styling).
2. Keep the policies accurate to what the bot actually does, and update a policy's "Last updated" date when its content changes.
3. Commit and push to `main`. GitHub Pages updates the live site in about a minute; check the live page afterwards.
